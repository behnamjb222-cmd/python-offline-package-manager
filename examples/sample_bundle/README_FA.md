# بسته‌ی آفلاین پکیج‌ها (POPM)

تاریخ ساخت: 2026-10-11T13:12:47+00:00
مخزن: sample_repository
مقصد: Python 3.12 / windows / x86_64
تعداد فایل‌های پکیج: 3

**این بسته فقط شامل فایل‌های پکیج پایتون است و خود مفسر Python را شامل نمی‌شود.**
باید Python 3.12 (با سیستم‌عامل و معماری سازگار) از قبل روی سیستم آفلاین نصب شده باشد.

## نصب (بدون نیاز به اینترنت)
۱. این پوشه (یا فایل ZIP استخراج‌شده) را به سیستم آفلاین منتقل کنید.
۲. در همین پوشه ترمینال را باز کنید و اجرا کنید (روش پیشنهادی: ساخت محیط مجازی جدید):

       python install_offline.py --venv C:\envs\myproject

   ابتدا با `--dry-run` ببینید چه چیزی نصب می‌شود. با `--yes` پرسش تأیید حذف می‌شود.
۳. اسکریپت ابتدا checksum های SHA-256 را بررسی می‌کند (metadata/checksums.json)، سپس با
   `pip install --no-index --find-links packages -r manifests/requirements.txt` نصب می‌کند و در پایان `pip check` را اجرا می‌کند.

می‌توانید بسته را در برنامه‌ی POPM هم وارد کنید (صفحه‌ی «انتقال و خروجی») و از رابط گرافیکی نصب کنید.

نکته: checksum فقط ثابت می‌کند فایل‌ها پس از ساخت بسته تغییر نکرده‌اند؛ هویت ناشر را ثابت نمی‌کند.

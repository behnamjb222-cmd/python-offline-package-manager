# مدیر پکیج آفلاین پایتون (POPM)

یک نرم‌افزار دسکتاپ (PySide6) که روی سیستم **دارای اینترنت** پکیج‌های پایتون را جمع می‌کند، در **مخازن آفلاین** تأییدشده و بدون تکرار
نگه می‌دارد، یک **بسته‌ی قابل‌حمل** (برای فلش) می‌سازد و روی سیستم **بدون اینترنت** نصب می‌کند — با رابط گرافیکی یا با اسکریپت
مستقل `install_offline.py`.

> **مهم:** بسته فقط شامل فایل‌های پکیج است، **نه خود مفسر Python**. محدودیت‌ها: [docs/KNOWN_LIMITATIONS.md](docs/KNOWN_LIMITATIONS.md)

## قابلیت‌ها (پیاده‌سازی‌شده)

* **محیط‌ها:** شناسایی Python از PATH، مسیرهای استاندارد، `py -0p`، رجیستری، pyenv/conda و پوشه‌های venv؛ افزودن دستی؛ نمایش نسخه، pip، سیستم‌عامل، معماری و برچسب‌های wheel؛ مقایسه‌ی دو محیط؛ تشخیص محیط‌های نامعتبر.
* **اسکن:** فهرست ساختاریافته با `importlib.metadata` در همان مفسر انتخابی (بدون تجزیه‌ی متن)، تشخیص منشأ (PyPI / محلی / VCS / URL / editable / نامشخص)، بررسی به‌روزرسانی، فیلتر/مرتب‌سازی، خروجی `requirements.txt` / JSON / CSV.
* **دانلود:** حل‌کننده‌ی خودِ pip (`install --dry-run --report`) فایل‌های لازم برای *سیستم مقصد* را تعیین می‌کند؛ POPM با نوار پیشرفت، سرعت، تلاش مجدد، لغو و بررسی هش مخزن دانلود می‌کند؛ چند نسخه از یک پکیج و محدودیت حجم پشتیبانی می‌شود.
* **مخازن:** چند مخزن مستقل، نمایه‌ی SQLite، حذف تکرار با SHA-256 بین مخازن، حذف منطقی/دائمی (با تأیید)، بررسی سلامت، فایل‌های تکراری، پشتیبان‌گیری/بازیابی فراداده، بازسازی از دیسک.
* **وابستگی‌ها:** بررسی ایستای کامل بودن (مفقود / تعارض / نبود فایل سازگار)، حل‌کننده‌ی pip به‌صورت dry-run، نصب آزمایشی در venv موقت.
* **نصب:** طرح ← تأیید صریح ← `pip install --no-index --find-links` در **venv جدید** (پیش‌فرض) یا محیط موجود، نتیجه‌ی هر پکیج، `pip check`، تلاش مجدد، فایل گزارش.
* **بسته‌ها:** ZIP شامل پکیج‌ها، manifest، checksum، گزارش سازگاری، `install_offline.py` و README فارسی/انگلیسی؛ تقسیم به چند قسمت؛ اعتبارسنجی پس از ساخت؛ استخراج امن (Zip Slip)؛ وارد کردن به مخزن.
* **امنیت:** بدون `shell=True`؛ تأیید برای عملیات مخرب؛ بررسی SSL به‌صورت پیش‌فرض روشن؛ پوشاندن اطلاعات حساس در لاگ؛ رمز Proxy هرگز ذخیره نمی‌شود.
* **رابط:** ۱۲ صفحه، تم روشن/تیره، فارسی (راست‌به‌چپ) و انگلیسی، اجرای پس‌زمینه، نوار پیشرفت، لغو.

## نیازمندی‌ها

* برای اجرا از سورس: Python **۳.۱۱ یا بالاتر** (محیط‌های *مقصد* می‌توانند Python ۳.۸+ باشند)
* `PySide6-Essentials` و `packaging` (فایل `requirements-dev.txt`)
* pip نسخه‌ی **۲۲.۲ یا بالاتر** در هر محیطی که اسکن/دانلود/نصب می‌شود

## اجرا

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
python main.py
```

داده‌ها (پایگاه داده، تنظیمات، لاگ، مخازن) در `%APPDATA%\POPM` ذخیره می‌شوند؛ با متغیر `POPM_HOME` قابل تغییر است. مخازن را می‌توانید هر جا بسازید.

## روند معمول

۱. **سیستم آنلاین:** «محیط‌های پایتون» ← شناسایی؛ «اسکن پکیج‌ها» ← انتخاب ← «ارسال به دانلودر»؛ **مقصد** (نسخه/سیستم‌عامل/معماری سیستم آفلاین) و مخزن را انتخاب و «شروع دانلود» را بزنید.
۲. «انتقال و خروجی» ← «ساخت بسته» ← فایل ZIP را به سیستم آفلاین ببرید.
۳. **سیستم آفلاین:** یا در پوشه‌ی استخراج‌شده `python install_offline.py --venv C:\envs\proj` را اجرا کنید، یا در POPM «وارد کردن بسته» ← «نصب آفلاین» ← بررسی خلاصه ← تأیید.
